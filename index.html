Privacy Policy

Applies to the Pinterest content-automation tool · Last updated September 2026

Enamora Labs is a one-person software studio run by Hans Oudeweernink. This page explains what one of its internal tools — used to publish pins to a single Pinterest account — does with data, in plain terms.

01Who runs this

Enamora Labs is the name under which Hans Oudeweernink builds personal tools. There is no separate company entity behind it — it's a sole proprietorship. This particular tool manages the Pinterest presence of I Love Colors Art, an Etsy shop also run by Hans.

02What the tool does

The tool is a desktop application that runs on my own computer. It reads artwork mockups and listing details I've already prepared, generates a title, description, and search-relevant keywords for each one, and publishes the result as a Pin to my own Pinterest boards, linking back to my own Etsy listings.

It has exactly one user: me. It is not distributed, not offered as a service, and does not act on behalf of anyone else's Pinterest account.

03Information it processes

  • Pinterest access token — issued via Pinterest's own OAuth login, stored encrypted on my own device only.
  • Artwork images and mockups — my own files, prepared before the tool ever runs.
  • Etsy listing text and links — my own shop data, entered by me.
  • Generated pin text — titles, descriptions and keywords produced from the above, optionally with help from a third-party AI text service (see below).

The tool does not read, collect, or store data belonging to other Pinterest users, pinners, or boards. It only writes to my own account.

04Third-party services involved

Two outside services are called while the tool runs, and only for the purpose stated:

  • Pinterest API — to publish pins and read my own board list. Governed by Pinterest's own privacy policy.
  • An AI text-generation provider (Anthropic or OpenAI, configurable) — receives the artwork image and listing text to draft a pin title and description. It does not receive my Pinterest credentials.

05What isn't collected

No cookies, no analytics, no tracking of any kind. Nothing is sold, rented, or shared beyond the two services named above. There is no server this tool reports back to — the token and logs stay on my own machine.
